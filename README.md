# Тұрғын үй жағдайын тексеру актілері (біріктірілген нұсқа)

Бір сайтта 4 акт түрі:

1. **Қарттардың үй бөлімшесіне арналған акт** — ересектерге үйде қызмет көрсету
2. **Балалардың үй бөлімшесіне арналған акт** — мүгедектігі бар балаларға үйде қызмет көрсету
3. **Күндіз болу орталықтарына арналған акт** — жартылай стационар (күндізгі орталық)
4. **Психоневрология бөлімшесіне акт** — 18 жастан асқан, І/ІІ топ мүгедектігі бар адамдар

## Маңызды: құпиялылық

Барлық деректер тек пайдаланушының браузерінде өңделеді. Ешқандай сервер, дерекқор (база данных) немесе бэкенд жоқ. Word құжаты толықтай браузерде жасалады (`docx` кітапханасы арқылы) және `file-saver` арқылы жүктеледі. Ешқандай ақпарат қайдай да серверге жіберілмейді немесе сақталмайды.

## Жергілікті іске қосу

```bash
npm install
npm run dev
```

## Деплой

```bash
npm run build
```

Бұл `dist/` қалтасын жасайды — оны Vercel, Netlify немесе кез келген статикалық хостингке жүктеуге болады. Environment variables қажет емес.

Vercel арқылы GitHub репозиторийін импорттағанда:
- Framework Preset: **Vite** (автоматты анықталады)
- Build Command: `vite build`
- Output Directory: `dist`
- «Optional Integrations» бөлімінде Supabase-ты қоспаңыз — ол бұл жобада қолданылмайды.

## Құрылым

```
src/
  main.tsx          — кіру нүктесі
  RootApp.tsx        — басты мәзір (4 актінің арасында ауысу)
  index.css          — ортақ стильдер
  forms/
    adults/          — ересектерге арналған акт
    kidsHome/         — балаларға (үйде) арналған акт
    kidsDay/          — балаларға (күндізгі орталық) арналған акт
    psychoneuro/       — психоневрология бөлімшесіне арналған акт
```

Әр акттің өз ішкі логикасы (өрістер, Word генерациясы) бастапқы жеке жобалардан өзгеріссіз көшірілді — тек ортақ басты мәзір қосылды.
